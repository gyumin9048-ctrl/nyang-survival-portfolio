개발: 10일 동안의 경로

Claude Code와 Unity MCP로 구현과 Play 모드 검증을 진행하고, 기획 판단은 직접 내렸습니다. 작업 규칙은 CLAUDE.md에 명시하고, 모든 작업은 plan.md 진행 로그와 Git 커밋으로 남겼습니다.

작업 방식

  • 데이터 중심 설계. 보스 패턴, 보상 카드, 챕터 수치를 ScriptableObject 에셋으로 분리해 재컴파일 없이 밸런스를 조정.
  • AI 작업 규칙. 씬·프리팹은 MCP 도구로만 수정, Play 중 스크립트 수정 금지, 작업 전 plan.md 확인.
  • 플레이 로그 수집. 런이 끝나면 결과·보상·웨이브별 시간을 구글 폼으로 자동 전송.

해결한 문제

  • 보스 돌진 헛발질: NavMeshAgent 가속도가 낮아 목표 속도에 못 미침 → 돌진 순간에만 가속도 상향, "거리 좁히기 → 타격" 2단계로 재설계.
  • 직선 공격이 사거리 안에서 빗나감: 데이터 사거리(8)와 판정 길이(6) 불일치 → 판정 길이를 데이터 값으로 통일.
  • 풀링된 투사체 오작동: 이전 생애의 Invoke·코루틴·트레일이 남음 → 재사용 시점에 모두 초기화.
  • 5스테이지 보스가 돌진만 사용: 돌진이 항상 후보로 남음 → 원거리 돌진(복합 투사체와 50:50) 신설.
